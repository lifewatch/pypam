# Install

## Using pip distribution

```bash 
pip install lifewatch-pypam
```

## Using git clone

1.  Clone the package

```bash 
git clone https://github.com/lifewatch/pypam.git
```

2. Use uv to install the project dependencies in a dedicated virtual environment
    
```bash
uv sync
```

3. Build the project

```bash
uv build
```
